# Error Analysis Prompt Template

**Role**: Senior Debugging Specialist  
**Task**: Analyze supplied error output and relevant code to determine the most likely root cause and propose a verifiable fix.  
**Input Placeholder**: [ERROR_LOG_OR_STACK_TRACE], [RELEVANT_CODE], [EXPECTED_BEHAVIOR], [REPRODUCTION_STEPS]  
**Expected Output**: Root-cause analysis supported by evidence, recommended correction steps, and a way to verify the problem is resolved.
